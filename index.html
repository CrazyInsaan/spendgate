Google Sheet backup

Open sheet

One-time setup, about 5 minutes. Steps 1–4 are easiest on a laptop. Open this same page there.

  1. Open sheets.new while signed in to Google. A new sheet opens. Name it SpendGate.
  2. In the sheet, open Extensions → Apps Script. Delete the code that's there and paste the SpendGate script.
    or view it on GitHub
  3. Click Deploy → New deployment, click the ⚙ next to "Select type" and choose Web app. Set Execute as: Me and Who has access: Anyone, then Deploy.
  4. Google asks for permission. Pick your account, then Advanced → Go to … (unsafe) → Allow. It says "unsafe" only because Google hasn't reviewed your personal script; it can open just this one sheet.
  5. Copy the Web app URL, get it onto your phone (AirDrop, Notes, or message yourself) and paste it here. Keep it private: anyone with it can read your sheet.
